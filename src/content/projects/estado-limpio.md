## The Problem

Citizens don't know when the garbage truck will pass through their street, resulting in accumulated trash, dirty streets, and constant complaints. Municipal authorities lack visibility over actual routes and collection service efficiency, making it impossible to optimize operations or address citizen concerns effectively.

## The Solution

**Estado Limpio** is an MVP platform developed for the InnovaTec innovation competition that enables real-time waste collection truck tracking via GPS. Citizens can monitor collection schedules and vehicle locations on their smartphones, while authorities have a complete administrative dashboard to supervise operations and optimize routes.

### How It Works

1. **For Citizens**:
   - Open the mobile app → View real-time map with truck locations
   - Check estimated arrival times for their street
   - Set personalized alerts for collection schedules
   - Report missed collections or issues

2. **For Operators**:
   - Trucks transmit GPS location in real-time
   - System automatically records completed routes
   - Dashboard shows real-time coverage and progress

3. **For Authorities**:
   - Web administrative panel built with Vue.js
   - Monitor route compliance and efficiency metrics
   - Identify uncovered zones and service gaps
   - Optimize resource allocation based on data

### Competition Success & Recognition

- **InnovaTec National Finalist**: Competed in InnovaTec innovation competition, advancing to the national stage after winning local and regional rounds
- **Government Interest**: Prototype presented to the Nayarit State Government, receiving strong interest for potential full-scale implementation

### Technology Stack

- **Mobile App**: Cross-platform Flutter application for Android and iOS with interactive maps and push notifications
- **Backend**: Firebase for real-time synchronization, authentication, and GPS data storage
- **Administrative Dashboard**: Vue.js single-page application with TypeScript for type safety
- **Additional Services**: Python backend services for data processing and analytics

### Result

A functional MVP validated through national competition that successfully demonstrated technical viability and market potential. The prototype proved that real-time tracking technology can significantly improve municipal waste collection services, earning recognition from both competition judges and government officials.
